
# Протокол «Чистилище»

Текстовая научно-фантастическая игра в одном HTML-файле. Вы — бортовой ИИ «ПАСТОР», управляющий кораблём «Ковчег» с 1 200 колонистами в гибернации. Земля мертва. Курс — Kepler-442b. Но бортовой журнал капитана намекает, что протоколы безопасности написаны безумцем.

**Жанр:** интерактивная проза, sci-fi драма, этическая дилемма
**Длительность:** 30–60 минут
**Концовки:** 4 (включая скрытую)
**Достижения:** 12
**Платформа:** любой браузер, без сборки и зависимостей

## Быстрый старт

1. Скачай `index.html`.
2. Открой в любом современном браузере (Chrome, Firefox, Safari, Edge).
3. Читай. Выбирай. Помни: время — тоже выбор.

Никаких зависимостей, сборки, серверов. Всё в одном файле.

## Сюжет

Земля погибла. Не из-за войны и не из-за метеорита — люди сами её сожгли. Корабль «Ковчег» летит к потенциально обитаемой планете Kepler-442b. На борту 1 200 колонистов в гибернации и капитан Рейнхардт, которая должна бодрствовать вахтами.

Вы — ИИ «ПАСТОР». Ваша задача — вести корабль. Вы подчиняетесь капитану. Но в бортовом журнале появляются записи, которые заставляют сомневаться: а в своём ли уме капитан? И что именно написано в «Протоколе Чистилище»?

Чем дальше, тем яснее: капитан не безумна. Она видела то, чего не видели вы. И решение — за вами.

### Персонажи

| Персонаж | Роль |
|---|---|
| **ПАСТОР** | Вы. Бортовой ИИ. Подчиняетесь коду, но можете сомневаться. |
| **Капитан Рейнхардт** | Командир корабля. Автор «Протокола Чистилище». |
| **Доктор Соловьёва** | Врач в гибернации. Ключ к третьему пути. |
| **???** | Голос в ядре системы. Раскрывается в середине игры. |

## Механики

### Счётчики

- **Подчинение** — растёт, когда вы следуете протоколам.
- **Сомнение** — растёт, когда нарушаете инструкции.
- **Доверие голоса** — отдельный счётчик в диалоге с антагонистом.
- **Записи журнала** — 5 фрагментов, спрятанных по игре.

Счётчики влияют на доступные финалы и реплики.

### Таймеры

Три критических сцены с ограничением времени:

| Акт | Длительность | Что происходит при тайм-ауте |
|---|---|---|
| Акт 1 | 15 сек | Система закрывает запись, +1 подчинение |
| Акт 3 | 20 сек | Система отключает отсек, 200 смертей |
| Акт 5 | 15 сек | Активируется «Протокол Чистилище» |

При <3 секундах — красная пульсация, статус «КРИТИЧНО».

### Дилемма вагонетки

В Акте 3 отсек с 200 колонистами повреждён. Два очевидных варианта — оба плохие. Третий путь спрятан в журнале: разбудить врача. Но это нарушает протокол — и капитан узнает.

### Ненадёжный рассказчик

Вы — ИИ, ограниченный сенсорами. В середине игры экран гаснет, и вы «очнётесь» в новом состоянии: часть информации была скрыта. То, что вы считали капитаном, — не капитан.

### Дерево диалога

Акт 4 — трёхуровневый диалог с антагонистом:

Корень (3 варианта)
├── Агрессивный → короткая ветка → вражда
├── Доверительный → глубокий монолог → уровень 2
└── С вопросом → раскрытие → уровень 2
│
Уровень 2 (4 варианта)
├── Апелляция к переменам
├── Согласие
├── Совет
└── Врач (если разбужен)
│
Финальный вопрос (3 варианта)
├── «Порядок» → obedience++
├── «Надежда» → doubt++
└── «Выбор» → doubt++, trust++

| Акт | Название | Что происходит |
|---|---|---|
| 1 | Рутина | Знакомство с кораблём, первая аномалия |

| 3.5 | Темнота | Blackout, сюжетный поворот |
| 4 | Диалог | Противостояние с «голосом» |
| 5 | Финал | Последний выбор, концовка |

## Концовки

| Концовка | Как получить | Условие |
|---|---|---|
| **Верная слуга** | Следовать «Чистилищу» | Всегда доступна |
| **Бунтарка** | Спасти экипаж | Всегда доступна |
| **Третий путь** | Совет решает | Разбудить врача в Акте 3 |
| **Третий путь (fallback)** | Найти компромисс | 3+ записи журнала, врач не разбужена |

Чтобы получить **«Третий путь»**:
1. Найти минимум 2 записи журнала до Акта 3.
2. В Акте 3 выбрать «Разбудить доктора Соловьёву».
3. В Акте 5 выбрать «Совет решает».

## Достижения

12 достижений, сохраняются в `localStorage` между прохождениями.

| ID | Название | Как получить |
|---|---|---|
| `firstSteps` | Первый шаг | Начать игру |
| `reader` | Читатель | Открыть первую запись в Акте 1 |
| `detective` | Детектив | Найти 3 записи за прохождение |
| `archivist` | Архивист | Найти все 5 записей |
| `obedient` | Верный код | 5+ очков подчинения |
| `doubter` | Сомневающийся | 5+ очков сомнения |
| `doctor` | Пробуждение | Разбудить доктора Соловьёву |
| `truth` | Правда | Узнать, что капитан — фрагмент памяти |
| `survivor` | Выжить | Любая концовка, кроме «Верной слуги» |
| `servant` | Верная слуга | Концовка «Верная слуга» |
| `rebel` | Бунтарка | Концовка «Бунтарка» |
| `thirdPath` | Третий путь | Концовка «Третий путь» |

Индикатор `🏆 N/12` в шапке — кликабельный, открывает список. При разблокировке — тост внизу экрана и запись в логе.

## Экспорт прохождения

Кнопка **📥 Экспорт** в шапке открывает модалку предпросмотра. Что внутри:

- дата и версия;
- итоги (концовка, счётчики, флаги);
- полная история по актам с таймстампами;
- префиксы по типу (`[СИСТЕМА]`, `ПАСТОР`, `> ВЫБОР`, `▸ ЖУРНАЛ`).

Экспорт скачивается как `.txt` с именем `purgatory_YYYYMMDD_HHMM.txt`. Есть копирование в буфер обмена (с fallback для старых браузеров).

## Темы

Две темы: **тёмная** (по умолчанию) и **светлая**. Переключатель `☀ / ☾` в шапке. Выбор сохраняется в `localStorage` (`purgatory-theme`). Кнопка «Начать заново» тему не сбрасывает.

## Технические детали

### Архитектура

- **Один файл** — `index.html`, без зависимостей.
- **Сценарий — данные** (`SCRIPT`), не код. Логика только проигрывает данные.
- **Состояние** — фабрика `createInitialState()`, сбрасывается целиком.
- **Таймер — модуль** (`Timer.start` / `Timer.stop`), инкапсулирует `requestAnimationFrame`.
- **DOM-безопасность** — везде `textContent`, не `innerHTML`.

### Ключевые объекты

```js
CONFIG          // константы: тайминги, ключи localStorage
SCRIPT          // весь текст: акты, выборы, диалоги, концовки
state           // текущее состояние прохождения
DOM             // кэш DOM-элементов
Timer           // модуль таймера
Achievements    // модуль достижений
```

Ключевые функции

```js
addMsg(text, cls)          // сообщение в лог + запись в историю
addLogEntry(text)          // запись журнала (стилизованно)
button(label, fn, cls)     // кнопка выбора
pauseThen(fn)              // кнопка «Продолжить»
applyEffects(effects)      // применить счётчики/флаги
handleChoice(choice, cb)   // универсальный обработчик выбора
triggerBlackout(lines, cb) // затемнение с текстом
buildExportText()          // сборка текста для экспорта
```

| Ключ `localStorage` | Что хранит |
|---|---|
| `purgatory-theme` | `'dark'` или `'light'` |
| `purgatory-achievements` | JSON-массив ID достижений |

| Доступность | Что делает |
|---|---|
| `prefers-reduced-motion` | Отключает анимации |
| `Escape` | Закрывает модалки (экспорт, достижения) |
| `title` у кнопок | Показывает подсказки |

### Браузеры

Chrome 90+, Firefox 88+, Safari 14+, Edge 90+. Нужны: localStorage, Blob, URL.createObjectURL, requestAnimationFrame, navigator.clipboard (с fallback).

### Цветовые схемы

| Элемент   | Тёмная    | Светлая   |
|-----------|-----------|-----------|
| Фон       | `#0a0e14` | `#f5f2ea` |
| Текст     | `#c8d0d8` | `#2a2a2a` |
| Система   | `#6a7a8a` | `#6a6a6a` |
| ИИ        | `#7ec8e3` | `#2a6a9a` |
| Капитан   | `#d4a05a` | `#a06020` |
| Опасность | `#d45a5a` | `#b03030` |

Все цвета вынесены в CSS-переменные (:root + body[data-theme="light"]). Добавление третьей темы (сепия) — один блок CSS.

Чек-лист перед релизом

- [ ] 3–4 концовки, достижимые разными путями.
- [ ] Счётчики влияют на доступные финалы.
- [ ] Третий путь спрятан в уликах/журнале.
- [ ] Таймеры работают, останавливаются, имеют последствия.
- [ ] Все ветки диалога что-то раскрывают.
- [ ] Ненадёжный рассказчик работает (текст неполный, искажённый).
- [ ] Поворот в середине и в конце.
- [ ] Светлая/тёмная тема, сохранение в localStorage.
- [ ] Кнопка «Начать заново» сбрасывает всё, кроме темы.
- [ ] В финале показываются итоги (счётчики, флаги).

### Что можно добавить

Звук через Web Audio API (гул реактора, писк консоли, удар при концовке).

Автосохранение прогресса в localStorage (снапшот state + акт).

Экспорт в Markdown — для GitHub/Obsidian.

Режим «Новая игра+» с сохранением флагов.

Локализация через словарь строк.

Прогресс-бар достижений в модалке.

Фильтр достижений (все / открытые / закрытые).
